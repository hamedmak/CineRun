# CineRun 🎬

CineRun is a modern, user-friendly web application for browsing and downloading movies. With a sleek interface and intuitive design, it provides an excellent movie discovery and download experience.

## Features

- **Movie Browser**: Browse through a curated collection of movies, including both classics and new releases
- **Search Functionality**: Easily search for your favorite movies
- **Multilingual Support**: Toggle between different languages for a localized experience
- **Responsive Design**: Works seamlessly across desktop and mobile devices
- **Categories**: Browse movies by different categories and genres
- **HD Quality**: Access to high-definition movie downloads
- **New Releases**: Stay updated with the latest movie releases
- **Best Movies Section**: Quick access to top-rated and popular films

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts (Inter)

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start browsing and downloading your favorite movies!
